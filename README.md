# Manish Sharma Profile Website

A modern, responsive Next.js + Tailwind CSS profile site designed for sharing with colleges, organizations and professional contacts.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build for production

```bash
npm run build
npm run start
```

## Deploy

This project is ready for Vercel, Netlify or another Node.js-compatible host. For Vercel, import the repository and deploy with the default Next.js settings.

## Before publishing

1. Replace `contact@rebellionrider.com` with the preferred public email address.
2. Verify the LinkedIn and YouTube profile URLs.
3. If desired, replace the profile image in `public/manish-sharma.png` with the final headshot.
4. Add a custom domain such as `profile.yourdomain.com`.

## LinkedIn

LinkedIn does not host a custom Next.js website inside the profile. Host this site on Vercel/Netlify/etc., then add the live URL to your LinkedIn Contact Info and Featured section.
